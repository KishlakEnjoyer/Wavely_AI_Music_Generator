# Wavely MusicGen

Добро пожаловать в **Wavely MusicGen** — веб-приложение для генерации и прослушивания музыки, разработанное с использованием Vue.js и локальной базы данных Supabase.

## 🚀 Инструкция по проверке проекта

Следуй этим шагам, чтобы получить доступ к приложению:

1. **Установите RadminVPN**  
   Скачайте и установите RadminVPN с официального сайта: [https://www.radmin-vpn.com/](https://www.radmin-vpn.com/)

2. **Подключитесь к сети**  
   Запустите RadminVPN и присоединитесь к сети.

3. **Название сети:**  
   `Wavely MusicGen`

4. **Пароль от сети:**  
   `kluchevoe_sostoyanie`

5. **Откройте приложение**  
   Перейдите по следующей ссылке в браузере:  
   [http://26.53.21.87:9090/](http://26.53.21.87:9090/)

6. **Проверяйте**  
   Наслаждайтесь музыкой и тестируйте функционал!

## 🛠 Используемые технологии

- **Vue.js** — фронтенд-фреймворк
- **Supabase** — локальная база данных и аутентификация
- **Docker** — контейнеризация сервисов
- **RadminVPN** — сеть для локального доступа

## ⚠️ Примечания

- Убедитесь, что вы подключены к сети `Wavely MusicGen` через RadminVPN.
- Приложение работает в тестовом режиме и доступно только в рамках VPN-сети.
- Если возникают проблемы с подключением, проверьте настройки брандмауэра и порты `9090` и `54321`.
